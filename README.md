# 每日任務平台

把工作和學習放在同一個地方的每日任務平台。

**網址：https://donna12301230.github.io/daily-tasks/**

## 裡面有什麼

## 不重複顯示的規則

- **今天頁是唯一的「今天」**：工作台的事項直接列在這裡，工作台裡面不再有自己的「今天」分頁（從月曆點日期仍可看某一天的細節）。
- **同一件事只出現一次**：同一天、名稱相近的工作台事項和平台任務／里程碑視為同一件事，只顯示平台那一列；勾一次，兩邊都會完成。工作台那邊先勾掉的，平台這邊也當作完成，不會跑到逾期。
- **固定時段不重複**：工作台那天已經排了同一條讀書線（多益、碩班、iPAS），或同一個時段的課，每週固定時段就不再列；它的「打開考古題／單字」按鈕會移到工作台那一列。
- **頁面標題**：上方分頁已經標出所在頁面，模組頁不再重複寫名稱。
- **沒內容就不出現**：單字、考古題沒有紀錄時不佔位置；專案狀態篩選只列有專案的狀態。
- **考試準備寫在學習目標裡**：考試不再有自己的準備清單，考試卡片顯示它接到的學習目標的進度和下一步；學習目標卡片顯示考試倒數（跟目標日同一天時只顯示一個）。舊的準備清單已併進目標步驟（目標裡已有的不重複，文字裡的日期變成期限），原本的清單備份在考試資料的 `prepMerged`。
- **同一件事兩邊連動**：工作台事項和平台的細項／里程碑／考試是同一件事時，會記下對應（工作台事項的 `link`，平台那筆的 `wb`）。不管在今天頁、專案表格、甘特圖、月曆哪裡勾完成或改日期，另一邊都跟著改。
- **矛盾提醒**：專案裡有細項超過專案結束日（或早於開始日）、里程碑不在專案期間內，專案頁上方會提醒；學習目標的步驟晚於目標日，卡片上會標「⚠ N 步晚於目標日」。
- **新增單字庫、新增筆記不放在畫面上**：新的單字庫或課程筆記用 AI 整理好一整套，再請 Claude 加進來。
- **專案任務以看板為主**：工作台的甘特圖直接讀「專案管理」看板的任務、「學習規劃」的步驟和「考試」，在甘特圖改日期、狀態、工時、負責人會寫回看板。工作台只保留不屬於專案的排程（IG 行銷、其他課程與行程）。第一次打開工作台時，會把工作台原本的工作接到看板上的同一筆（工時、負責人搬過去，看板沒有的補進看板），工作台的資料本身不刪除，只標記接到哪一筆（`board`／`exam`）。

## 資料存在哪裡

- 用 Google 登入後，任務、專案、工作台、考古題作答紀錄存在 Firebase（專案 `vocab-trainer-7716`）的 `users/{你的 uid}/apps/...`，只有你自己讀得到（規則見單字練習 repo 的 `firestore.rules`）。
- 單字練習沿用它原本的雲端同步（同一個 Google 帳號）。
- 這個 repo 只有程式碼，沒有任何個人資料。

## 更新內建網站

作業系統筆記、生成式 AI 講義、考古題、單字練習的程式碼是從原本的 repo 複製進 `apps/` 的。原本的網站更新後：

```
python tools/build.py
git add -A && git commit -m "同步內建網站" && git push
```

工作台（`apps/workbench/`）直接在這個 repo 裡維護。

## iPAS 資安考古題（初級、中級）

`apps/ipas/` 直接在這個 repo 裡維護：原卷 PDF 放在 `apps/ipas/pdf/`（檔名「場次_I11…」「場次_I12…」（初級）或「場次_I21…」「場次_I22…」（中級）。官網只放最近一屆，之後拿到中級其他年度的 PDF 照同樣檔名放進來就好），題目資料 `data.json` 和有圖表題目的截圖 `img/` 由程式從 PDF 產生。之後有新的場次（例如 113-2、114 年），把 PDF 放進 `apps/ipas/pdf/` 再執行：

```
python tools/ipas_extract.py
python tools/ipas_chapters.py
python tools/exam_plan.py
```

第一支抽題目和截圖，第二支替每題標章節（初級另外配到書的小節，目錄在 `tools/ipas_books.py`），第三支更新每日進度的題目順序（平台打開時會發現題目變了，把那一科明天起還沒做的重排）。需要 poppler（pdftotext、pdftohtml、pdftoppm）。程式會檢查每份題數（初級 50、中級 40）、每題 4 個選項和答案，不對會列出來。中級的複選題答案存成「ACD」，網站上先點選項再按「送出」。

改了 `apps/` 底下任何網站後，把 `index.html` 裡的 `BUILD` 換一個值，使用者打開平台時才會載入新版（GitHub Pages 會讓瀏覽器快取 10 分鐘）。

## 考古題每日進度（中山、iPAS 初級、多益）

每一科一條讀書線，都依章節排、每天一筆：

| 科目 | 題目來源 | 一天份量 | 期限（考前一個月） | 開始 |
|---|---|---|---|---|
| 中山計概、MIS | 中山資管考古題（C 語言章節不排） | 選擇 2 題或問答 1 題；排不完才把「2＋1」併成 3 題 | 碩班入學考（預設 2028/2/1） | 明天 |
| iPAS 管理、技術 | 以書為主：《iPAS 初級資安工程師攻略》管理概論篇（90 小節）、技術概論篇（126 小節）的目錄（`tools/ipas_books.py`），搭配初級 109–115 年＋樣題各 550 題，每題配到最相關的小節 | 讀幾個小節（看頁數）＋這幾節的考古題；題目多的小節題目分幾天做，照剩下的天數平均 | iPAS 初級（預設 2027/5/22，參考 115 年 5/23） | 明天 |
| iPAS 中級規劃、防護 | iPAS 中級 115 年，各 40 題（之後補其他年度） | 照期限平均分，同一天不跨章 | iPAS 中級（預設 2027/8/22） | iPAS 初級考完隔天 |
| 多益 Vol.7、Vol.8 | 官方全真試題，各 2 回 | 一天一個 Part；每回 Part 做完後的週六計時做一次整回 | 多益第一、二場（預設 2027/7/11、9/12） | 前一場考試（iPAS、多益第一場）的隔天 |

- 期限讀平台「考試」裡的日期：碩班入學考（種類入學考、名稱有碩／研究所／中山／資管）、名稱有 iPAS（初級；名稱有「中級」的算中級）、名稱有多益或 TOEIC（名稱寫第一場／第二場，不然照日期）。沒建就用上表的預設日期。
- 不排的日子：週日、假日、空大期中／期末考那一週（115 學年度的已內建，之後的在「考試」建種類期中考／期末考的就會避開）；iPAS 衝刺期（iPAS 初級考前三週）中山暫停。
- 考試日期、空大考試週改了，打開平台時那一科明天起還沒做的會照新條件重排（工作台 `meta.examSig` 記每一科上次排的條件），做過的、今天以前的不動。
- 多益單字事項不附「＋App 20 分」（`meta.vocabAppOff`，一次性拿掉）。
- 延後某一天的考古題時預設會勾「後面的考古題整組一起往後延」：同一科後面還沒做的一起往後挪同樣的可讀書天數，另一科和其他讀書線不動；取消勾選就只移那一天。
- 題目順序存在工作台的 `EXAM_PLAN`，由程式產生（改了考古題資料或 iPAS 章節後重跑）：

```
python tools/ipas_chapters.py
python tools/exam_plan.py
```

平台第一次讀到工作台時，會把還沒完成的計概(一)、MIS 課本、補充和它們的看題／做題標成刪除（`replacedBy: "exam"`，資料還在）。事項上的題號可以點，直接跳到考古題那一題。進度看「學習 → 讀書進度」，每天要做的也會列在「今天」和月曆。

## 擴充新的模組類型

在 `index.html` 的 `TYPES` 加一個類型（`label`、`desc`、`view(mod)`），或像內建網站一樣指定 `src` 放一個獨立頁面。
